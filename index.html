Skills

Just ask. Bax takes it from there.

None of this is a mode you switch on or a command to memorize. You ask; Baxter works out which of these it needs and does it.

Shops around

Four dishwashers, three insurance quotes, the same flight on six sites — it reads the listings, works out the true cost of each, and tells you which one wins, and why.

Does the reading

Point it at the forty-page report, the terms nobody reads, or an argument spread across a dozen threads. You get the answer, not a stack of links.

Teaches itself

Figure something out once and it keeps the trick: a site that fought it last week is routine this week. You never explain the same thing twice.

Keeps watch

The price you're waiting on, the filing that's due, the story you're following — it checks on its own and pings you when something actually changes, so you're not the one refreshing the page.

Remembers

Notes carry across every conversation, so nothing gets re-explained. Ask what you decided back in March and it goes and looks.

Keeps the list

Anything bigger than one chat gets its own living doc — what's decided, what's still open. It keeps that current as things move, so you don't have to.

Nudges you

Ask for a reminder and it books it in your timezone — once on Thursday, or every weekday at nine. It shows up whether or not anyone's around.

Does the busywork

A messy spreadsheet, the tedious arithmetic, a column of numbers that should be a chart — it writes the code, runs it, and hands back the file.

Security

Secure by design.

Anyone who can message Baxter is writing part of what it reads — so the rules that matter can't be talked out of. They live in the code around Bax, the container Bax runs in, and Discord itself.

Keys stay on your machine
Everything runs locally. No middleman, and no account to sign up for.
No logins to hand over
Baxter brings its own bot and its own inbox, so it never touches your Discord or email account.
Can't read its own keys
By default they sit somewhere Baxter can't open, so a hijacked run has nothing to leak.
Stays in its own folder
It reads and writes only inside its own workspace, nowhere else.
You pick who reaches Baxter
Only the email addresses you list get through. Leave the list empty and it answers no one.
Can't message strangers
It can't open a DM with anyone, and any new email it sends goes only to you.
Setup

Get up and running.

Install Baxter, give it a model to think with, then open a shell — from there Baxter walks you through the rest itself.

  1. 01

    Install it

    One line. It checks for Docker, git, and make, clones Baxter, scaffolds app/.env, puts the baxter CLI on your PATH, and builds the container images. Safe to re-run.

    curl -fsSL https://bax.bot/install.sh | bash
  2. 02

    Pick a model

    Give Baxter a brain — any model that can call tools works, and OpenRouter is the default. It's the one thing you set by hand, since Baxter needs a model before it can help with the rest.

    # app/.env
OPENROUTER_API_KEY=sk-or-...
OPENROUTER_MODEL=openai/gpt-4o
  3. 03

    Let Bax do the rest

    Open a shell and just ask. Now that it can think, Baxter helps you get set up.

    baxter shell
    baxterModel's wired up. I just can't reach you yet.
    youhow do I finish setting up?
    baxterOne thing left: a Discord bot token so I can reach you. I'll walk you to it — paste it here and I'll write it into app/.env and bring myself up.
